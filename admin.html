التوصيل والإرجاع

طرق الدفع

فعّل الطرق اللي بدك إياها، وحط معلومات الحساب. ما في ولا طريقة بتطلب من الزبون بيانات البطاقة على الموقع.

PayPal والفيزا بيندفعوا جوّا الموقع عن طريق بوابة PayPal الرسمية. كلمة test يعني وضع الاختبار (Sandbox)، ما في فلوس حقيقية. للدفع الحقيقي: من developer.paypal.com ← Apps & Credentials ← Live انسخ الـ Client ID وحطه هون، والفلوس بتنزل بحساب PayPal تبعك.

أكواد الخصم

قاعدة البيانات (Firebase)

لما تربطها، كل الطلبات بتنحفظ بمكان واحد وبتشوفها هون من أي جهاز، والكميات بتنقص أوتوماتيك مع كل طلب. مجانية للمتاجر الصغيرة.

كيف أربطها؟ (10 دقايق، مرة وحدة)
  1. افتح console.firebase.google.com وسجّل بحساب Google، واضغط Create a project. سمّيه nool-store. Google Analytics مش ضروري.
  2. من القائمة: Build ← Firestore Database ← Create database، اختار أقرب منطقة (مثلاً eur3)، وStart in production mode.
  3. Build ← Authentication ← Get started ← Email/Password فعّله. بعدين تبويب Users ← Add user: حط إيميلك وكلمة سر، هاد حساب الأدمن.
  4. بنفس Authentication: Settings ← Authorized domains ← Add domain: ضيف aseel-shamia.github.io.
  5. Project settings (الترس) ← تحت Your apps اضغط </> (Web)، سمّيه وسجّله، وانسخ الـ firebaseConfig كامل والصقه تحت.
  6. اكتب إيميل الأدمن تحت، وانسخ قواعد الحماية اللي بتطلع، والصقها بـ Firestore ← Rules واضغط Publish.
  7. اضغط انشر على الموقع، وبعدين سجّل دخول هون واضغط ارفع الكميات.

الإشعارات والإحصائيات

افتح web3forms.com، اكتب إيميلك واضغط Create Access Key. المفتاح بيوصلك على الإيميل، والصقه هون. بعدها كل طلب جديد بيوصلك بتفاصيله على الإيميل.

من analytics.google.com: اعمل Property وWeb stream لرابط الموقع، وانسخ الـ Measurement ID. بتشوف الزيارات والمنتجات اللي انشافت وانضافت للسلة والمبيعات.

الطلبات

بتظهر هون الطلبات اللي انعملت من هالمتصفح. اربط قاعدة البيانات وسجّل دخول لتشوف كل الطلبات.

النشر على الموقع

اربط الأدمن بالريبو مرة وحدة، وبعدها زر انشر على الموقع بيرفع التعديلات لحاله.

المفتاح بينحفظ بهالمتصفح بس، وما بيطلع لأي مكان غير GitHub.

كيف أعمل المفتاح؟
  1. على GitHub: صورتك فوق ← Settings ← Developer settings ← Personal access tokens ← Fine-grained tokens ← Generate new token.
  2. سمّيه nool-admin، وتحت Repository access اختار Only select repositories واختار الريبو تبعك بس.
  3. تحت Permissions ← Contents اختار Read and write.
  4. اضغط Generate token، انسخه وحطه هون. ما تبعته لحدا.

شغلك بينحفظ كمسودة بهالمتصفح بشكل تلقائي.
